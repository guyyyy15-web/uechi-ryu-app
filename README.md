# 上地流 Uechi-Ryu Training Companion

מדריך אימון אישי לקראטה אוצ'י ריו — קובץ HTML יחיד, עצמאי, בלי תלות בשרת.

## תוכן
- **הוג'ו אונדו** — 13 תרגילי עזר, עם דיאגרמות SVG (מבט צד/מלמעלה/תקריב נשק)
- **קאטות** — 8 הצורות של הסגנון, לפי סדר חגורות, עם סרטון הדגמה ובונקאי (יישום קרבי) לכל אחת
- **חימום** — רשימת שלבים לפני אימון, ניתנת לסימון
- **מילון מונחים** — מונחי יפנית עם חיפוש, סינון ותמונות מקור
- **מחולל אימון** — לחיצה אחת בונה אימון אקראי מתוך התרגילים באתר

## שימוש
פתחו את `index.html` בכל דפדפן. הניווט בין החלקים הוא פנימי (JavaScript), אין
צורך בשרת או בחיבור לאינטרנט — מלבד תמונות הממוזערות/קישורי היוטיוב בעמוד הקאטות.

## מבנה הפרויקט
```
index.html      קובץ האפליקציה הבנוי (זה מה שפותחים)
src/            עמודי המקור, אחד לכל חלק באפליקציה
build.py        סקריפט שממזג את src/*.html ל-index.html אחד
references/     מקורות מחקר + תמונות רפרנס אמיתיות (עם קרדיט ורישיון)
game/           משחק עצמאי (Deck Runner) — לא חלק מהאתר ולא עובר דרך build.py
```

## המשחק (`game/`)

בתיקייה `game/` יושב **Deck Runner** — משחק ריצה אינסופית תלת-ממדי בסגנון
וויאקסל, נפרד לגמרי מאתר האוצ'י ריו. הוא **לא** נבנה על ידי `build.py`, לא
מופיע כעמוד ב-`index.html`, ואין קשר בין השניים: בנייה מחדש של האתר לא נוגעת
בו, ועריכת המשחק לא מצריכה הרצת `build.py`.

- כתובת חיה: https://guyyyy15-web.github.io/uechi-ryu-app/game/
- הרצה מקומית: המשחק משתמש ב-ES modules, ולכן חייב שרת (לא `file://`):
  ```
  python3 -m http.server 8000
  # http://localhost:8000/game/
  ```
- ספריית three.js (גרסה r170, רישיון MIT) שמורה בתוך `game/vendor/` כדי
  שהמשחק יעבוד בלי תלות ב-CDN. אין לערוך את הקובץ הזה ידנית.
- תיעוד מלא של המשחק: `game/README.md`.

## עריכה
לשנות תוכן: ערכו את הקובץ הרלוונטי תחת `src/`, ואז הריצו:
```
python build.py
```
זה בונה מחדש את `index.html`. **אין לערוך את `index.html` ידנית** — הוא נדרס
בכל הרצה. `index.html` כן נשמר במעקב Git (מחויב לריפו) כדי שהאתר יעבוד גם דרך
מצב הפרסום הבסיסי של GitHub Pages ("Deploy from a branch") מבלי להזדקק להגדרה
נוספת — **חובה להריץ `python build.py` ולהעלות (commit) את התוצאה בכל שינוי
תוכן**, אחרת הגרסה החיה תישאר ישנה.

## פרסום (GitHub Pages)
הריפו כולל גם את `.github/workflows/deploy.yml`, שבונה ומפרסם את האתר אוטומטית
אם מפעילים בהגדרות **Settings → Pages → Build and deployment → Source: GitHub
Actions**. אם לא הופעלה הגדרה זו, GitHub Pages ישתמש כברירת מחדל ב-`index.html`
שנשמר בריפו (ראו לעיל) — ולכן חשוב לוודא שהוא תמיד מעודכן ונשמר ב-Git.

### אנליטיקס
מחובר GoatCounter (ללא עוגיות, ללא צורך בהודעת הסכמה) דרך משתנה
`GOATCOUNTER_CODE` בראש `build.py`. יש להירשם בחינם ב-
https://www.goatcounter.com/ ולהחליף את הערך בקוד האתר שלכם (ה-subdomain)
לפני שמפרסמים בפועל — אחרת הנתונים לא ייאספו לשום מקום אמיתי.
